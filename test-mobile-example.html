Test Page for Mobile Alternate Detection

This page contains a mobile alternate link in the head section.

The mobile version is at: https://m.example.com/page

What is Mobile Alternate Link?

Mobile alternate links are used to point to a mobile-specific version of the page.

Example: <link rel="alternate" media="only screen and (max-width: 640px)" href="https://m.example.com/page">

Testing Instructions

  1. Save this file locally
  2. Run: npm run test:mobile file:///path/to/this/file.html
  3. The script should detect the mobile alternate link
